# Architecting Clean Code

A structured curriculum titled *"The Software Architect's Gauntlet: From Clean Code to System Design"*, organized by the DSC Cairo University Chapter. This repository contains the course materials for an 18-session, project-based program aimed at developers who want to master software design principles, design patterns, and system design at a senior/FAANG-engineering level. Each session pairs theoretical content with a competitive team project and a mandatory code-review deep-dive.

## Features

- Full course overview describing the weekly cadence: main session → project challenge → team collaboration → weekly report → code review
- Session-by-session breakdown covering SOLID principles (SRP, OCP, LSP, ISP, DIP) with real-world case studies (e.g. the Knight Capital Group trading disaster)
- Creational design pattern modules: Simple Factory, Factory Method, Abstract Factory, Builder, and Prototype
- Each session includes a `session_content.md` (lecture material and objectives) and a `project_description.md` (the team project brief for that week)
- Content structured for a team-based, competitive learning format with mentor-led code reviews

## Tech Stack

This is a documentation/curriculum repository — content is written entirely in Markdown, with no executable code included. Topics covered are language-agnostic object-oriented design principles and design patterns.

## Project Structure

| Path | Description |
|---|---|
| `Architecting_Clean_Code_Course_Overview.md` | Top-level course description, weekly cycle, and full session/module roadmap |
| `Module 1 The Foundations of Steel (SOLID & Advanced Principles)/` | Sessions 1–4: technical debt, code smells, and the five SOLID principles |
| `Module 2 The Genesis of Objects (Creational Patterns)/` | Sessions 5–6: factory patterns, builder, and prototype patterns |
| `*/session_content.md` | Lecture notes, objectives, and case studies for each session |
| `*/project_description.md` | The weekly team project brief tied to that session's topic |

## Installation

No installation is required — this is a documentation repository. Clone it to read or contribute to the material:

```bash
git clone https://github.com/OmarElzero/Architecting_Clean_Code.git
cd Architecting_Clean_Code
```

## Usage

Browse `Architecting_Clean_Code_Course_Overview.md` first for the full roadmap, then open each module/session folder in order to follow the curriculum:

```bash
cat "Architecting_Clean_Code_Course_Overview.md"
cat "Module 1 The Foundations of Steel (SOLID & Advanced Principles)/Session 1 Beyond Clean Code — The Philosophy of Maintainability/session_content.md"
```
